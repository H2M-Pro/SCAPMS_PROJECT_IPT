# Student Continuous Assessment and Progress Monitoring System (SCAPMS)

## About the Project

The **Student Continuous Assessment and Progress Monitoring System (SCAPMS)** is a web-based system developed to support the management of student continuous assessments and academic progress.

The system provides a platform where instructors can create and manage online assessments, students can access and submit assessments, objective questions can be automatically marked, and assessment results and feedback can be managed and monitored.

## Main Features

* User authentication and role-based access
* Student management
* Instructor management
* Course management
* Online assessment creation and management
* Question and option management
* Assessment scheduling
* Online assessment submission
* Automatic marking of objective questions
* Result calculation and management
* Student feedback
* Student performance and progress monitoring
* Performance reports

## System Users

The system is designed for three main user roles:

* **Student** — accesses courses, takes assessments, submits answers, views results and feedback, and monitors academic progress.
* **Instructor** — manages assessments and questions, monitors submissions, reviews results, and provides feedback.
* **Academic Officer** — manages courses and monitors student and course performance through reports.

The system uses **MySQL** as its database management system.

The database is designed to manage users, students, instructors, academic officers, courses, assessments, questions, options, submissions, answers, results, and feedback.

## Project Objectives

The project aims to:

1. Provide online management of student assessments.
2. Allow instructors to create and manage assessments.
3. Allow students to access and submit assessments online.
4. Automate marking of supported objective questions.
5. Provide timely assessment results and feedback.
6. Support monitoring of student academic performance.
7. Improve the storage and management of assessment records.

## Scope

The system focuses on student continuous assessment and progress monitoring.

It does not cover unrelated university services such as payroll, library management, accommodation, finance, or physical examination invigilation.
